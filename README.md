# Ислам Арсакаев — сайт-визитка

Личная страница брокера чартерных рейсов Ислама Арсакаева (ArsakaevKSA):
прямые рейсы Грозный и Махачкала — Медина и Джидда. Главная задача страницы —
чтобы человек из Instagram или Telegram сразу понял, с кем имеет дело, и в один тап
написал в WhatsApp или Telegram.

Без сборки и зависимостей: открыть `index.html` — и работает.

## Как посмотреть

```
node dev-server.js
```

Откроется на http://localhost:5196. Проверка вёрстки в headless Chrome:
`node tools/check.mjs pc|phone|se|android <папка для снимков>`.

## Что где менять

| Что | Где |
|---|---|
| Имя, должность, текст под именем | `assets/js/data.js` → `person` |
| Цифры (10 000+ клиентов и т. д.) | `data.js` → `facts` |
| Ссылки: WhatsApp, Telegram, Instagram | `data.js` → `links` |
| Текст, который подставится в WhatsApp | `data.js` → `links[0].url` |
| Число подписчиков канала | `data.js` → `links[1].note` |
| Телефон и почта | `data.js` → `contacts`, **плюс** `contact.vcf` и блок `ld+json` в `index.html` |
| Направления на табло и карте | `data.js` → `routes.airports` и `routes.list` (коды IATA) |
| Условия: багаж, зам-зам, группы | `data.js` → `routes.conditions` |
| Услуги | `data.js` → `services` |
| Биография, языки, ценности, цитата | `data.js` → `about` |
| Случай из практики | `data.js` → `trust` |
| Фото | `assets/img/islam-1034.jpg` и `islam-640.jpg` (квадрат) |

После правки CSS или JS поднять `?v=` в `index.html`, чтобы телефоны не показывали старую версию из кэша.

## Мобильная версия

Сайт будут открывать в основном с телефона, поэтому:

- на iPhone 14 и обычном Android кнопка «Написать в WhatsApp» видна на первом экране без прокрутки;
- когда кнопки первого экрана не видно, снизу выезжает панель «WhatsApp · Telegram · Позвонить»
  (на маленьком iPhone SE — сразу при открытии); над финальным блоком панель прячется;
- каждая карточка-ссылка нажимается целиком;
- «Сохранить контакт» скачивает `contact.vcf` с фото — телефон предложит добавить в контакты.
  Во встроенном браузере Instagram скачивание может не сработать — там помогают кнопки звонка и WhatsApp.

## Откуда оформление

| Элемент | Что это |
|---|---|
| Карточки ссылок | Посадочный талон: отрывной корешок с перфорацией и вырезами, «выход» с кодом, штрихкод |
| Табло рейсов | Перекидное табло Solari, как в аэропортах: буквы пролистываются и встают на коды IATA (GRV, MCX, MED, JED) |
| Карта | Штурманская карта: сетка через 5°, аэропорты по настоящим координатам, расстояния по большому кругу |
| Решётка в финале | Рошан — деревянные решётчатые окна старой Джидды (квартал Аль-Балад, наследие ЮНЕСКО) |
| Зелёный цвет | Флаг Саудовской Аравии и Зелёный купол Мечети Пророка ﷺ |
| Графитовый фон | Подобран под фон студийного портрета, чтобы фото растворялось в странице |

## Источники текста

- биография, контакты и фото — страница `arsakaev.tilda.ws`;
- рейсы, авиакомпании, багаж, услуги и случай с регистрацией — канал `t.me/arsakaevKSA`
  (посты 148, 153, 225, 286, 291, 302, 309).

Цены на сайт специально не вынесены — они меняются каждую неделю. Кнопка «Даты и цены — в канале» ведёт туда, где они актуальны.
